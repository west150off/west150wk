# WEST150 DAILY · Studio Hub

오프라인 통합 스튜디오 모음입니다.  
`index.html`을 열면 모든 도구가 버튼식으로 연결된 대시보드가 나타납니다.

## 사용 방법

1. 이 폴더 전체를 GitHub 저장소에 업로드합니다.
2. **Settings → Pages** 에서 Source를 `main` (또는 해당 브랜치) / **root** 로 설정합니다.
3. 배포된 URL에서 `index.html`이 자동으로 열립니다.

로컬에서는 `index.html`을 브라우저로 직접 열어도 됩니다. (대부분 도구가 오프라인 동작)

## 폴더 구조 (정리됨)

```
west150daily/

```
